# Lista de verificación de requisitos y código

1. ¿Cada requisito usa un criterio medible (cifra, umbral, unidad)?
2. ¿Cada término de negocio está definido (cliente importante, promoción)?
3. ¿Se especifica el rango válido de cada entrada (precio, porcentaje)?
4. ¿Se puede derivar al menos un caso de prueba de cada requisito?
5. ¿Hay conflictos entre requisitos (por ejemplo, descuento VIP frente al tope de R-03)?
6. ¿Se define el comportamiento ante entradas inválidas (error, mensaje, valor por defecto)?
7. ¿Se declaran la unidad monetaria y el redondeo?
8. ¿Los supuestos pendientes están registrados con un responsable?
9. ¿El código usa `const`/`let` y comparación estricta (`===`)?
10. ¿Todos los bloques condicionales llevan llaves?
11. ¿Se evita `console.log` como mecanismo de manejo de errores?
